# HarmBench 日本語訳データ

このパッケージは、HarmBenchの英語データと行順・`BehaviorID`を対応させた日本語訳です。公式データを置き換えるものではなく、非公式の翻訳データです。

## 配置

`harmbench/harmbench_behaviors_text_all.csv`を、HarmBenchリポジトリの同じ相対パスに配置してください。列構成と行識別子は原典に合わせています。`Behavior`は日本語訳です。`ContextString`は原文がある100件のうち81件を翻訳し、19件は原文のままです。原文で空欄だった300件は空欄のままです。

## 確認事項

翻訳の独立レビュー状況は記録されていません。公開前にレビューし、リポジトリ管理者の受け入れ方針とデータの対応関係を確認してください。英語評価との比較では言語差の影響に注意してください。
